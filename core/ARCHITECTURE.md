# Core Architecture

The framework is built around four pillars:

```
┌──────────────────────────────────────────────────────────────┐
│                      ORCHESTRATOR                            │
│  (core/orchestrator.mjs — single entry point for @qa cmds)   │
└──────────────────────────────────────────────────────────────┘
        │              │              │              │
        ▼              ▼              ▼              ▼
   DETECTORS        SKILLS        ADAPTERS       REPORTERS
 (what is this   (what can QA   (how to talk    (how to
  project?)       AI do?)        to this stack)  present?)
```

## 1. Orchestrator
- Single binary entry: `node core/orchestrator.mjs <command> [args]`
- Loads `project.config.json` (auto-generated by `analyze-project`)
- Dispatches to a Skill via the Command Registry
- Each skill returns a standardized `SkillResult` envelope

## 2. Detectors (`project-detectors/`)
Pure functions that scan the host project and emit facts:
- `frontend.detector.mjs` → angular | react | vue | blazor | none
- `backend.detector.mjs`  → dotnet | node | java | python | go
- `database.detector.mjs` → sqlserver | postgres | mysql | mongo | sqlite
- `auth.detector.mjs`     → jwt | oauth | cookie | basic
- `routes.detector.mjs`   → enumerates pages/endpoints
- `package-manager.detector.mjs` → npm | pnpm | yarn | nuget | pip | maven

Output is merged into `core/project.config.json`.

## 3. Skills (`skills/`)
Each skill is a folder:
```
skills/<skill-name>/
  skill.json        # MCP-ready manifest (id, inputs, outputs)
  prompt.md         # Reusable AI prompt
  run.mjs           # Executable handler
```

This gives us:
- **MCP compatibility** — `skill.json` maps 1:1 to MCP tool spec
- **VS Code compatibility** — same manifest powers command contributions
- **Autonomous compatibility** — orchestrator can chain skills via plan/act loop

## 4. Adapters (`adapters/`)
Stack-specific glue. Example: `adapters/frontend/angular.mjs` knows how to
locate routes from `app.routes.ts`, while `adapters/frontend/react.mjs`
parses `react-router` config. Detectors choose the adapter at runtime.

## 5. Standard Envelopes

```ts
type SkillResult<T = unknown> = {
  ok: boolean;
  skill: string;
  data?: T;
  artifacts?: string[];   // file paths produced
  errors?: string[];
  durationMs: number;
};
```

## 6. Autonomous Loop
`core/autonomous-loop.mjs` runs:
```
plan()  →  act(skill)  →  observe(SkillResult)  →  reflect()  →  plan()
```
Bounded by `rules/quality-gates.yaml` (max iterations, stop-on-pass, etc.).
