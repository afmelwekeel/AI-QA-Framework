# AI QA Framework — Init & Reset Actions

Loaded on demand when the user runs `/aiqa-init` or `/aiqa-reset`. Not loaded on normal activation.

---

## Framework Init — /aiqa-init

Register the framework with the user's IDE/agent tools. Safe to re-run: existing files are skipped.

Creates:
- `.github/agents/ai-qa-framework-qae.agent.md` — Rayan in the Copilot agents dropdown
- `.github/prompts/aiqa-*.prompt.md` — chat autocomplete (Copilot)
- `.claude/commands/aiqa-*.md` — Claude Code slash commands (if Claude Code selected)
- `.cursor/rules/aiqa-*.mdc`, `.windsurf/rules/aiqa-*.md` — if selected

Commands registered (one file each, generated by `bin/utils/init.mjs`):
`aiqa-help`, `aiqa-setup`, `aiqa-create-testcases`, `aiqa-run-tests`, `aiqa-fixbug`, `aiqa-fullworkflow`, `aiqa-listskills`, `aiqa-listworkflows`, `aiqa-reset`.

Run: `npx ai-qa-framework init` (or `node bin/cli.mjs init`). Then report created / skipped files.
Next step for the user: `/aiqa-setup`.

---

## Framework Reset — /aiqa-reset

⚠️ **Framework Reset — /aiqa-reset**

This will permanently delete:
- Generated test cases, results, screenshots, bug files and summaries under `{output_folder}/test-cases/` and `{output_folder}/test-results/`
- All entries in `{output_folder}/TEST-CASES-LOG.yaml` (the file is reset to `templates/TEST-CASES-LOG.template.yaml` with empty `files: []` and zero `totals`)
- The QA history table in `_memory/qae-sidecar/qa-history.md`
- `.github/agents/ai-qa-framework-qae.agent.md` and `.github/prompts/aiqa-*.prompt.md`

It keeps (unless the user also asks for them):
- `{output_folder}/EXECUTION-GUIDE.md`, `INDEX.md`, `DATABASE-TABLES.md` — project facts made by `/aiqa-setup`. Ask: "Delete these too?" Default no.
- `config.yaml`, `_memory/qae-sidecar/qa-preferences.md`
- `agents/`, `workflows/`, `_config/`, `skills/`, `core/`, `commands/`, `reusable-prompts/`, `templates/`
- Non-aiqa files in `.github/`

**Type `YES` to confirm, or anything else to cancel.**

On confirmation, in order:

1. Clear outputs:
   ```powershell
   cd "{project-root}/AI-QA-FRAMEWORK"
   if (Test-Path "TestResult/test-cases")   { Remove-Item "TestResult/test-cases/*"   -Recurse -Force }
   if (Test-Path "TestResult/test-results") { Remove-Item "TestResult/test-results/*" -Recurse -Force }
   ```
   (Also remove EXECUTION-GUIDE.md / INDEX.md / DATABASE-TABLES.md only if the user said yes.)
   Recreate `TestResult/test-results/bugs/BUGS-INDEX.md` from `templates/BUGS-INDEX.template.md`.

2. Overwrite `_memory/qae-sidecar/qa-history.md`:
   ```markdown
   # QA History Log

   > Updated after each executed test-case file.
   > Reset on: {current_date}

   | Date | Story | File | Pass | Fail | Blocked | Bugs |
   |---|---|---|---|---|---|---|
   ```

3. Remove Copilot integration files:
   ```powershell
   $agentFile = "{project-root}/.github/agents/ai-qa-framework-qae.agent.md"
   if (Test-Path $agentFile) { Remove-Item $agentFile -Force }
   Get-ChildItem "{project-root}/.github/prompts/aiqa-*.prompt.md" -ErrorAction SilentlyContinue | Remove-Item -Force
   ```

4. Report what was removed. Next: `/aiqa-init`, then `/aiqa-create-testcases <story>`.
